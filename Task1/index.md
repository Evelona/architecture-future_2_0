# Проблемные места:
1.Перегруженный DWH и устаревшая инфраструктура (Приоритет: 🔴 Must have, cрочно)
- SQL Server 2008 не масштабируется горизонтально, медленно работает с большими объёмами данных, не поддерживает современные подходы к аналитике.
- Отчёты формируются по 1–2 часа, time-to-market — недели, новые запросы аналитиков тормозят IT.

2.Слабая изоляция доменов и плохая масштабируемость (Приоритет: 🔴 Must have, cрочно)
- Например, интеграция фармацевтики или оборудования требует доработки шины, DWH и интерфейсов.
- Медленный запуск новых направлений → упущенные возможности на рынке

3.Нет нормального самообслуживания для аналитиков (Приоритет: 🟠 Should have, важно)
- Нет витрин, нет гибкости в построении отчётов → аналитики ждут разработки

4.Нет гибкого и прозрачного IAM (🟠 Should have, важно в долгосрочной перспективе)

5.Недостаточная событийность и реактивность систем (🟡 Could have)
