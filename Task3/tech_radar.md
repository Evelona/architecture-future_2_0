#  Tech Radar: Будущее 2.0

## ADOPT
| Направление        | Технология / Подход       | Комментарий                     |
| ------------------ | ------------------------- | ------------------------------- |
| BI                 | Power BI                  | Основной инструмент отчётности  |
| Языки / Фреймворки | Python, Java, Golang      | Для ИИ и финтех-сервисов        |
| Инфраструктура     | Apache Camel              | Шина для интеграций             |
| Хранилища данных   | Microsoft SQL Server 2008 | Централизованный DWH            |
| UI/UX-интерфейсы   | Power Builder             | Старый интерфейс для операторов |


## TRIAL
| Направление   | Технология / Подход | Комментарий                                         |
| ------------- | ------------------- | --------------------------------------------------- |
| DWH           | SQL Server 2008     | Требует модернизации: не масштабируется, устаревший |
| Шина данных   | Apache Camel        | Нет событийной обработки, плохо масштабируется      |
| UI-фреймворки | Power Builder       | Морально устарел, плохо поддерживается              |




## Переход к новым технологиям
| Направление     | Новая технология         | Комментарий                                     |
| --------------- | ------------------------ | ----------------------------------------------- |
| DWH / Data Lake | ClickHouse, S3, Postgres | Разделение витрин, отказ от монолитного DWH     |
| Интеграции      | Kafka / Event Mesh       | Событийная архитектура                          |
| ML / аналитика  | MLflow, Airflow, dbt     | Автоматизация пайплайнов, прозрачность          |
| Веб-приложения  | React, FastAPI, gRPC     | Современные веб-интерфейсы и API между доменами |
| BI              | Self-service BI          | Свобода бизнес-пользователям собирать отчёты    |
