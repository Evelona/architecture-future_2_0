# домены и логика разделения

| Домен                      | Назначение                                           | Причины выделения                                                                 |
| -------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------- |
|  **Медицинский**      | Работа с пациентами, картами, снимками, назначениями | Содержит предметную область медицины. Логика сильно отличается от финансовой и BI |
|  **Финансовый**          | Оплаты, кредиты, задолженности, тарифы               | Обособленный процессинг, свой ритм изменений, часто имеет внешние API             |
|  **Аналитика и BI**      | Агрегация, отчёты, self-service BI                   | Использует данные из других доменов, нужен только на чтение                       |
| **ИИ и анализ снимков** | Инференс, хранение моделей, обучение                 | Имеет специфические требования по ресурсам и масштабированию                      |
|  **Интеграции и шлюзы**  | Подключение внешних API и систем                     | Отвечает за стабильность и безопасность внешних соединений                        |


Медицинский → ИИ-домен: передаёт снимки, получает метки/предсказания

Медицинский → Финансовый: назначение → запрос тарифа/оплаты

Медицинский → Событийная шина → BI: события поступлений, диагнозов

ИИ → Data Lake → BI: обучение моделей + агрегации

Финансовый → Data Lake → BI: транзакции, долги


| Аргумент                                       | Что даст                                                                 |
| ---------------------------------------------- | ------------------------------------------------------------------------ |
|  Независимость изменений                     | Можно развивать ИИ или аналитику без риска поломать медицину или финансы |
|  Упрощённое тестирование                     | Тесты покрывают локальную бизнес-логику, проще CI/CD                     |
|  Масштабируемость                            | Например, ИИ можно вынести в отдельную среду с GPU                       |
|  Безопасность                                | Разделение доменов помогает ограничить доступы (например, к медданным)   |
|  DWH больше не единственная точка интеграции | Снижается нагрузка, повышается устойчивость                              |
