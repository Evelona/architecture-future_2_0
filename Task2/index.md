# домены и логика разделения

| Домен                      | Назначение                                           | Причины выделения                                                                 |
| -------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------- |
|  **Медицинский**      | Работа с пациентами, картами, снимками, назначениями | Содержит предметную область медицины. Логика сильно отличается от финансовой и BI |
|  **Финансовый**          | Оплаты, кредиты, задолженности, тарифы               | Обособленный процессинг, свой ритм изменений, часто имеет внешние API             |
|  **Аналитика и BI**      | Агрегация, отчёты, self-service BI                   | Использует данные из других доменов, нужен только на чтение                       |
| **ИИ и анализ снимков** | Инференс, хранение моделей, обучение                 | Имеет специфические требования по ресурсам и масштабированию                      |
|  **Интеграции и шлюзы**  | Подключение внешних API и систем                     | Отвечает за стабильность и безопасность внешних соединений                        |
